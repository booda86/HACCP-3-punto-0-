HACCP Manager Pro - PWA iPhone

Questa versione funziona da Safari e può essere aggiunta alla schermata Home.

Funzioni:
- Dashboard
- Magazzino/lotti
- Scadenze
- Registro temperature
- Controllo automatico dei limiti
- Backup JSON
- Report stampabile/PDF
- Funzionamento offline
- Salvataggio locale sul dispositivo

Pubblicazione consigliata: GitHub Pages.
Dopo la pubblicazione, apri il link in Safari > Condividi > Aggiungi alla schermata Home.

Importante: esegui periodicamente un backup, perché i dati sono salvati sul dispositivo/browser.
